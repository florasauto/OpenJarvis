Agents

Each agent has its own setup script. Running one switches the machine's active config, so run the setup for the agent you want, then restart the server. The chat panel talks to whichever agent is active now.

Every agent runs on this machine with a local model. Nothing you type here leaves the building unless an agent's notes say otherwise.
Five agents work from the overnight notes, and they only see notes after the refresh script has run. Leave this running: uv run python scripts/floras-auto/refresh-notes.py ~/FlorasAuto/overnight-notes --every 600

How this page works

It is a single static page served by the OpenJarvis API server at /floras.html. Status comes from /health, /v1/info, and /v1/models. Chat uses the OpenAI-compatible /v1/chat/completions endpoint with streaming. The server decides which agent answers, based on the active config.
